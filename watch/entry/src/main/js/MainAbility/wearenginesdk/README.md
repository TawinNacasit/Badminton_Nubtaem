# Wear Engine Lite SDK file required

Do not replace this directory with a guessed implementation. Download the Lite Wearable JavaScript SDK from Huawei's Wear Engine SDK page, then place its verified `wearengine.js` (and accompanying integrity file, if supplied) here before importing/building in DevEco Studio.

The source expects the official exports `Builder`, `Message`, and `P2pClient`, matching Huawei's official/community Lite Wearable sample.
